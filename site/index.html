Dlaczego sieć musi być ustawiona jako „Prywatna”?

Gdy podłączasz kabel LAN lub łączysz się z Wi-Fi, system Windows domyślnie oznacza nową sieć jako Publiczną (Public). W tym trybie Zapora Windows (Windows Firewall) całkowicie odcina komputer od innych urządzeń w mieszkaniu — blokuje wykrywanie pakietów UDP oraz protokół USB/IP.

Po przełączeniu na profil Prywatny (Private): Zapora Windows pozwala obu komputerom komunikować się ze sobą wewnątrz Twojego routera, a aplikacje LanUsb.Server i LanUsb.Client natychmiast się odnajdują!

Jak przestawić sieć na Prywatną (2 proste sposoby):

Sposób 1: W programie LanUsb (1 klik)

Wystarczy kliknąć przycisk „⚡ Zmień na Prywatną” lub „🌐 Ustawienia sieci” bezpośrednio na górnym pasku aplikacji LanUsb.Server lub LanUsb.Client!

Sposób 2: Ręcznie w ustawieniach Windows
  1. Otwórz Ustawienia Windows → Sieć i Internet.
  2. Kliknij swoje połączenie (Ethernet lub Wi-Fi).
  3. W sekcji *Typ profilu sieci* zaznacz: Sieć prywatna.

Architektura

Jak działa LanUsb w 3 krokach

1

Komputer z USB (Serwer)

Uruchamiasz LanUsb.Server.exe. Program wykrywa urządzenia (np. Stream Deck, Cam) i pozwala jednym kliknięciem kliknąć Udostępnij (Bind).

2

Komputer do streamu (Klient)

Uruchamiasz LanUsb.Client.exe. W 2 sekundy serwer pojawi się samoczynnie. Klikasz Podłącz (Attach) lub włączasz Auto-łącz.

3

Wirtualne USB w Windows

Sterownik montuje wirtualny kontroler USB. OBS Studio, Discord, Elgato Software i gry widzą urządzenie tak, jakby było fizycznie wpięte kablem!

FAQ

Często zadawane pytania

Czy ta aplikacja jest całkowicie darmowa i legalna? +

Tak, w 100%! LanUsb korzysta z otwartego standardu protokołu USB/IP (RFC Linux/Windows) oraz darmowych, oficjalnie podpisanych sterowników jądra Windows Open Source (usbipd-win oraz usbip-win2). Nie ma żadnych ukrytych opłat, licencji ani limitu urządzeń.

Czy występuje opóźnienie (input lag) w grach i streamowaniu? +

W domowej sieci lokalnej spiętej kablem Ethernet (1 Gbps) opóźnienie transmisji pakietów USB wynosi zazwyczaj poniżej 1 milisekundy (<1 ms). Przyciski na Stream Decku, mikrofony i kamery reagują w czasie rzeczywistym.

Dlaczego Klient nie widzi Serwera w sieci? +

Najczęstsze przyczyny to:

  1. Profil sieci Windows: sieć na jednym z komputerów jest oznaczona jako Publiczna zamiast Prywatna.
  2. Zapora Windows: uruchom plik Otworz-Porty-Firewall.bat na obu komputerach.
  3. Możesz również wpisać adres IP serwera ręcznie w polu „Ręczne IP serwera” w aplikacji LanUsb.Client.
Jak działa funkcja Auto-Connect? +

Wystarczy zaznaczyć urządzenie w LanUsb.Client i kliknąć przycisk ⭐ Auto-łącz. Klient zapamiętuje unikalny identyfikator sprzętowy (VID:PID). Po ponownym uruchomieniu komputera lub wybudzeniu ze snu, LanUsb automatycznie odnajdzie serwer i zamontuje urządzenie USB w tle!
